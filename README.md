# My C Journey

This repository contains my progress in C programming. It includes projects focused on memory management, data structures, and modular design.

## Repository Structure

The project is organized into folders, each containing its own source code and Makefile.

### MyCJourneyPt.1: Employee Record System
This project covers dynamic memory allocation for structs. It generates and manages employee data using pointers and header files.

### MyCJourneyPt.2: Dynamic Matrix Operations
This project focuses on multidimensional data. It allows creating matrices, filling them with data, and extracting square submatrices based on coordinates.

---

## How to Build and Run

Each folder includes a Makefile to compile the code using clang.

1. Navigate to the project folder:
   cd MyCJourneyPt.2

2. Compile the project:
   make

3. Run the program:
   ./MyCJourneyPt2

4. Clean build files:
   make clean
